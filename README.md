# One Word From Grandma: Chatterbox

[![make.fun](https://make.fun/badge.svg)](https://make.fun) [![Built with AI](https://make.fun/badge-ai.svg)](https://make.fun) [![Bounty](https://make.fun/badge-bounty.svg)](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16)

Hand Grandma an AI chatbot and she will not call it an LLM—she will squint at a three-paragraph reply to her two-word question and scold the phone like a talkative grandchild who never stops talking: "Oh hush, you little **Chatterbox**." Warm, mildly baffled, and naturally tied to "chat," **Chatterbox** captures Grandma's texting voice when the screen just keeps going on and on.

## How to Run

```bash
python3 main.py
```

## Expected Output

Stdout:

```text
Chatterbox (10 bytes)
```

Written to `/output/entry.txt` (10 UTF-8 bytes, no trailing newline):

```text
Chatterbox
```
